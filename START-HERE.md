# Start here on your Mac

1. Extract the ZIP.
2. Open Terminal. Type `cd `, drag the extracted project folder into Terminal, and press Return.
3. Run:

```bash
bash start-mac.command
```

4. Wait for “Uvicorn running”, then open http://127.0.0.1:8002.
5. Click Load synthetic example, then Run local review.

No API key is needed for local review. README.md explains how to enable optional LLM feedback. Keep the Terminal window open while using the app. Paste any error message into our conversation if setup fails.
